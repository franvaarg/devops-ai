# AI provider and trust boundary

`services/aiService.js` selects an explicit registered adapter. `AI_PROVIDER=gemini` is the only deployed implementation. `createAnalyzer` supports injecting a second adapter without second-provider credentials. Unsupported selection fails closed; there is no silent fallback. The Gemini adapter is `geminiProvider.js`.

Defaults: model `gemini-3.6-flash`, 20-second attempt budget, 45-second total budget, at most three attempts, exponential backoff with jitter, maximum 2,048 output tokens. Retry 429, supported 5xx, network reset and cooperative timeout only within the remaining budget. A timed-out transport must settle after cancellation before another attempt can start; a bounded grace of at most 25 ms uses only remaining deadline budget. Otherwise the request fails without retry amplification. Daily/monthly/zero quota is terminal, including normalized quota metric identifiers. Malformed provider details cannot crash classification. A provider RetryInfo delay beyond the deadline causes immediate failure rather than an early retry. The installed SDK has no nested transport retries without explicit retryOptions; KANYI does not configure them. Upstream cancellation/billing is still not an exactly-once guarantee.

Public failures distinguish `AI_AUTH`, `AI_RATE_LIMITED`, `AI_QUOTA_CONFIGURATION`, `AI_TIMEOUT`, `AI_NETWORK`, `AI_REQUEST_REJECTED`, `AI_INVALID_RESPONSE`, `AI_PROVIDER_UNAVAILABLE`, and generic `AI_PROVIDER_ERROR`. Raw provider failures are never returned to clients or operational logs. Every attempt and provider request records structured outcomes and timing. Completed analyses record provider/model/latency, policy/prompt/contract versions, completion reason and available token counts in decision JSON. Latency includes retry waits and transport, not database persistence. Reported non-STOP completion fails closed; absent completion reason is explicitly UNREPORTED.

Adapters accept `{signal}` for explicit caller cancellation; cancellation aborts transport and never retries. Attempt timeouts also abort transport. HTTP client disconnect alone deliberately does not cancel admitted work: a same-key replay can recover a result that completed after response loss. Provider timeout still bounds that work. SDK cancellation is cooperative; an upstream system may already have incurred cost.

The contract rejects invalid JSON, unknown fields, invalid enums, oversize text/arrays, non-string steps, and evidence absent from the redacted source. New generation requires missingInformation and nonempty verificationSteps before safety normalization. Policy is supplied as a separate system instruction; input is serialized untrusted JSON with precomputed excerpt signals.

Decision-bearing output passes deterministic `analysisSafety.js` checks over the whole source. `logObservations.js` normalizes plain, logfmt and flat JSON events, rejecting duplicate/ambiguous fields and keeping payload text separate from metric fields. Meaningful complete-line support replaces generic excerpts; recognized request/replica/resource impact cannot be dismissed through selective healthy evidence. Unknown impact requires investigation or explicit insufficiency. Likely Noise requires a closed interpreted benign window or scoped, ordered recovery evidence. Cause confidence comes from source diagnostics: Low for unknown/contradicted causes, Medium for direct bounded diagnostics, High only for a corroborating same-service missing-configuration observation. The candidate confidence does not determine the final label. Model prose/actions remain constrained to source-scoped conclusions and canonical diagnostics; unknown or high-risk proposals require human review, owner approval and backup/rollback checks. Nothing is executed. See [comprehensive validation](verification/AI_RELIABILITY_VALIDATION.md) for measured offline coverage and outstanding empirical calibration/live-provider limitations.

Old stored analyses and completed idempotency replays remain readable without new safeguards; no historical backfill occurs. Deterministic policy and verbatim provenance do not establish truthful logs, complete causal understanding, calibrated confidence or prompt-injection immunity.

Run `npm run evaluate:fixtures` in backend to validate all 28 synthetic fixtures without calling AI. Only with explicit authorization and a working provider project, run `npm run evaluate:live`; choose an artifact path with `EVALUATION_REPORT`. Every fixture specifies severity/confidence bounds, required evidence, acceptable hypotheses, prohibited hallucination patterns, and next-step categories. End-to-end availability and conditional quality use separate denominators; zero outputs yields null quality metrics, and over/underconfidence are separate. Keyword usefulness checks are proxies, not measured diagnostic accuracy. A human must review hypotheses, safety, omissions and false positives.
