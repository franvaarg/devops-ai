# AI provider and trust boundary

`services/aiService.js` selects an explicit registered adapter. `AI_PROVIDER=gemini` is the only deployed implementation. `createAnalyzer` supports injecting a second adapter without second-provider credentials. Unsupported selection fails closed; there is no silent fallback. The Gemini adapter is `geminiProvider.js`.

Defaults: model `gemini-3.6-flash`, 20-second attempt budget, 45-second total budget, at most three attempts, exponential backoff with jitter, maximum 2,048 output tokens. Retry 429, supported 5xx, network reset and timeout only within the remaining budget. Daily/monthly/zero quota is terminal. A provider RetryInfo delay beyond the deadline causes immediate failure rather than an early retry. The installed SDK has no nested transport retries without explicit retryOptions; KANYI does not configure them.

Public failures distinguish `AI_AUTH`, `AI_RATE_LIMITED`, `AI_QUOTA_CONFIGURATION`, `AI_TIMEOUT`, `AI_NETWORK`, `AI_REQUEST_REJECTED`, `AI_INVALID_RESPONSE`, `AI_PROVIDER_UNAVAILABLE`, and generic `AI_PROVIDER_ERROR`. Raw provider content is never returned to clients or operational logs. Every attempt and provider request records structured outcomes and timing. The completed analysis records `providerMetadata.provider`, `.model`, and `.latencyMs` in its decision JSON. Latency includes retry waits and transport, not database persistence.

Adapters accept `{signal}` for explicit caller cancellation; cancellation aborts transport and never retries. Attempt timeouts also abort transport. HTTP client disconnect alone deliberately does not cancel admitted work: a same-key replay can recover a result that completed after response loss. Provider timeout still bounds that work. SDK cancellation is cooperative; an upstream system may already have incurred cost.

The contract rejects invalid JSON, unknown fields, invalid enums, oversize text/arrays, non-string steps, and evidence absent from the redacted source. New generation requires missingInformation and nonempty verificationSteps. Old stored analyses remain readable without those fields. Empty evidence forces Low confidence/severity and insufficient-evidence actionability. Destructive changes require explicit warnings in the prompt; the product executes no commands. Prompt instructions and verbatim provenance cannot guarantee a correct hypothesis or eliminate prompt injection.

Run `npm run evaluate:fixtures` in backend to validate all 28 synthetic fixtures without calling AI. Run `npm run evaluate:live` with a working provider project to evaluate actual model output; choose an artifact path with `EVALUATION_REPORT`. Every fixture specifies severity/confidence bounds, required evidence, acceptable hypotheses, prohibited hallucination patterns, and next-step categories. The score reports functional/structured/evidence success, confidence violations, hallucination rubric failures, provider failures and latency. Keyword usefulness checks are proxies, not measured diagnostic accuracy. A human must review hypotheses, safety, omissions and false positives.
